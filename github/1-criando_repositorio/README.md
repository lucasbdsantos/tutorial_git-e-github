# Criando um Repositório no GitHub

Antes de enviar o código do seu computador para a internet, você precisa criar um espaço para ele no GitHub. Esse espaço na nuvem é chamado de **Repositório Remoto**. 

Diferente do comando `git init` (que cria um repositório local na sua máquina), este processo é feito de forma visual diretamente pelo site do GitHub.


## Passo a Passo para Criar o Repositório no GitHub

1. Acesse o site do [GitHub](https://github.com) e faça login na sua conta.
2. No canto superior direito da tela, clique no botão **"+"** (ao lado da sua foto de perfil) e selecione **"New repository"** (Novo repositório).
3. Na página que se abrir, preencha as seguintes informações:
   * **Repository name (Nome do repositório):** Escolha um nome simples e curto para o seu projeto (evite usar espaços ou acentos; use traços para separar as palavras, como `meu-primeiro-projeto`).
   * **Description (Descrição - Opcional):** Uma frase curta explicando sobre o que é o seu projeto.
   * **Public or Private (Público ou Privado):** 
     * **Público:** Qualquer pessoa na internet pode ver o seu projeto (ideal para portfólios).
     * **Privado:** Apenas você e as pessoas que você autorizar poderão ver o código.
   * **License (Licença - Opcional):** Define o que outras pessoas podem ou não fazer com o seu código (por exemplo, a licença *MIT* permite que qualquer pessoa use e modifique seu projeto livremente).
4. Deixe as outras opções desmarcadas (como adicionar README ou .gitignore) se você já tiver uma pasta pronta no seu computador.
5. Clique no botão verde **"Create repository"** (Criar repositório) no final da página.


## Conectando e enviando seu projeto local para o GitHub

Após clicar em criar, o seu repositório remoto estará vazio. O próprio GitHub exibirá uma tela com instruções de como enviar os arquivos que estão na sua máquina para lá. 

Mas se você quer entender melhor o que cada comando faz e a sua importância, vá para o seguinte arquivo do repositório: [Criando um repositório](../../git/2-git_na_pratica/criacao_repositorio.md).
