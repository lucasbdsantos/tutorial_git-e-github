# Atualizando seu Repositório Local (git pull)

Quando você trabalha em equipe ou utiliza mais de um computador, é muito comum que o repositório no GitHub (remoto) receba novas atualizações que ainda não estão no seu computador (local). 

Para buscar essas novidades e atualizar a sua máquina com a versão mais recente do projeto, nós usamos o comando `git pull`.

## Como sincronizar as atualizações

Para trazer as alterações do GitHub para a sua máquina, siga este passo a passo:

1. Abra a pasta do seu projeto no computador.
2. Clique com o **botão direito do mouse** em um espaço vazio e selecione **"Git Bash Here"**.
3. No terminal, digite o seguinte comando:

```bash
# Baixa as novidades do GitHub e as mescla automaticamente no seu código local
git pull
```
