# Acompanhando Repositórios

No GitHub, o recurso **Watch** serve para você acompanhar de perto todas as novidades, discussões e alterações de um repositório específico. 

Diferente do botão *Star* (que funciona como um favorito silencioso), o *Watch* é um sistema ativo de **notificações**. Ao ativar o *Watch* em um projeto, você diz ao GitHub que quer ser avisado sempre que algo importante acontecer por lá.


## Como configurar o Watch (Níveis de Acompanhamento)

Nem todo mundo quer receber e-mails a cada ponto e vírgula alterado em um código. Por isso, o GitHub permite que você configure o nível de notificações que deseja receber.

Ao clicar no botão **"Watch"** (localizado no canto superior direito do repositório, ao lado do botão *Star*), você verá as seguintes opções:

* **Participating and Mentions (Padrão):** Você só receberá notificações se alguém citar diretamente o seu nome de usuário (ex: `@lucasbdsantos`) ou se você estiver participando ativamente de alguma discussão na página.
* **All Activity:** Você receberá notificações para absolutamente **tudo** o que acontecer no repositório (novos commits, novas issues, novos pull requests abertos, etc.). *Ideal para projetos que você usa muito no seu dia a dia!*
* **Ignore:** Desativa todas as notificações do repositório, mesmo se marcarem você.
* **Custom (Personalizado):** Permite que você escolha exatamente o que quer acompanhar. Por exemplo, você pode pedir para ser notificado apenas se uma nova versão do projeto for lançada (*Releases*).


## Qual a diferença entre Star e Watch?

É muito comum que iniciantes confundam esses dois recursos. Veja este resumo simples para nunca mais esquecer:

| Recurso | O que ele faz? | Como funciona na prática? |
| :--- | :--- | :--- |
| **Star (Estrela)** | Favorita o projeto | Salva o repositório em uma lista no seu perfil para você consultar no futuro. **Não envia notificações.** |
| **Watch (Observar)** | Acompanha o projeto | Envia e-mails ou notificações no seu perfil sempre que houver novas atualizações ou discussões no repositório. |
